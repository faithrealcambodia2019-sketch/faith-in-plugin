# Blessing story feed visibility update

Version: 5.5.204

Changes applied:
- Blessing posts are no longer rendered as normal cards in the Home Feed stream.
- Blessings remain visible in the Blessing stories carousel and Blessing story viewer.
- Blessing music remains story-only and continues to auto play in the Blessing viewer.
- Added an in-Blessing comment input so users do not need to open a hidden feed card to comment.
- Updated the empty feed message when only Blessings exist.

This keeps Add Blessing working like a story feature instead of a normal feed post.
