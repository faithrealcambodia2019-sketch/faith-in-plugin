# Blessing Christian Music Update

Added optional Christian/worship audio support to the Add Blessing flow.

## Included
- New Music button inside Add Blessing.
- Users can upload MP3, M4A, AAC, WAV, OGG, OGA, or OPUS audio.
- Blessing composer shows an audio preview and remove button before publishing.
- Published Blessing stories show a music player inside the viewer.
- Feed Blessing posts show a small music player without breaking photo/text Blessings.
- Audio files are stored in the existing post media JSON, so no new database table or column is required.

## Note
Only upload Christian/worship music the user owns or has permission to share.
